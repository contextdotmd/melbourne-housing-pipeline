# Surrogate keys via `dbt_utils.generate_surrogate_key`

All dimension keys are MD5 hashes over separator-joined, null-sentinelled column values,
generated by `dbt_utils.generate_surrogate_key` rather than hand-rolled SQL.

## Consequences

This avoids the two failure modes of an ad-hoc `hash()` approach: engine hash functions are not
guaranteed stable across versions, and concatenating without a separator makes `('ab', 'c')`
collide with `('a', 'bc')`. It is also portable, which matters given ADR-0001's porting story.
